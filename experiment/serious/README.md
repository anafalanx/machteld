# Serious corpus: machteld/Tcl versus Python

This directory contains the preregistered 180-cell follow-up to the small
machteld agent pilots. It compares fresh-agent authoring on the complete,
independently validated 30-task Tika serious corpus:

- 30 tasks;
- two arms, machteld/Tcl and Python;
- three independent trials per task and arm;
- 90 visible cases and 464 hidden cases;
- 445 novel unique hidden rows after 17 visible overlaps and 2 repeated hidden
  rows in the inherited corpus;
- 180 subject cells, all run with no early stopping.

The primary quantity is the task-weighted solve-rate difference Δ. Practical
equivalence requires the frozen Jeffreys-posterior decision rule and the ±0.10
margin in `EXPERIMENT.md`; matching raw percentages alone are insufficient.

This experiment is additive. It does not replace or modify the earlier
`experiment/` micro-pilot or `experiment/run_probe/` study.

## Layout

```text
import_corpus.py  reproducible neutral import from _tika
corpus/           30 neutral tasks and exact hash provenance
primers/          matched arm-specific factual references
refs/python/      generated Python oracles from source ref_python
refs/machteld/    separately authored Tcl oracles; never generated by importer
reference-verification.json  preflight replay of all 60 references
bin/              checking, setup, grading, analysis, and bundle tools
runs/             generated blind cells and frozen runtimes (Git-ignored)
attempts/         supervisor-owned check snapshots/logs (Git-ignored)
results/          frozen grading and analysis bundles (Git-ignored)
```

The neutral task schema is exactly:

```text
id, fn, in, out, desc, difficulty, family, tags,
visible, hidden, provenance
```

`visible` and `hidden` retain the original case arrays unchanged. Each task's
`provenance` object records the exact source path/hash and description-only
normalization. `corpus/PROVENANCE.json` records hashes for every source task,
generated task, generated Python reference, the source report, and the importer.

## Reproduce and validate the corpus

From `C:\dev\_machteld`:

```powershell
# Rebuild the neutral tasks, Python references, and provenance from _tika.
C:\dev\z.exe python -I -S -B experiment/serious/import_corpus.py

# Verify that the checked-in projection is byte-for-byte reproducible.
C:\dev\z.exe python -I -S -B experiment/serious/import_corpus.py --check
```

The expected summary is:

```text
30 tasks, 90 visible, 464 hidden
case novelty: 17 hidden-visible overlaps, 2 hidden repeats, 445 novel unique hidden
difficulty: 4 mid, 18 hard, 8 very-hard
family: 12 validator, 7 number-theory, 7 bit-encoding, 4 interpreter
```

The importer deliberately does not write `bin/` or `refs/machteld/`.

## Experiment quick start

Read `EXPERIMENT.md`, `SUBJECT_PROTOCOL.md`, and `RUNBOOK.md` before generating
cells. Then run:

```powershell
# Exercise apparatus rejection/integrity paths and validate all 60 references.
C:\dev\z.exe python -I -S -B experiment/serious/bin/selftest.py
C:\dev\z.exe python -I -S -B experiment/serious/bin/verify_refs.py

# Generate the complete deterministically shuffled matrix once.
C:\dev\z.exe python -I -S -B experiment/serious/bin/setup_runs.py --seed 20260711

# Assign all 180 cells in manifest order to fresh no-context subjects.
# After final solutions, metadata, and attempts are frozen:
C:\dev\z.exe python -I -S -B experiment/serious/bin/grade_runs.py `
  --manifest experiment/serious/runs/manifest.json `
  --metadata experiment/serious/subject-metadata.jsonl
C:\dev\z.exe python -I -S -B experiment/serious/bin/analysis.py `
  --rows experiment/serious/results/rows.json

# Seal and verify the closed result bundle.
C:\dev\z.exe python -I -S -B experiment/serious/bin/bundle.py write
C:\dev\z.exe python -I -S -B experiment/serious/bin/bundle.py verify
```

Setup copies a machteld runtime into `runs/_frozen/machteld.exe` and an isolated
standard-library Python tree into `runs/_frozen/python`. Its default machteld
source is `experiment/serious/runtime/machteld.exe` when present, otherwise the
already frozen `experiment/run_probe/runtime/machteld.exe`. Pass
`--machteld PATH` before the first setup only when intentionally freezing a
different runtime, and record that choice.

Setup refuses to overwrite submissions, attempts, metadata, results, modified
public files, or a non-pristine generated cell. Its `--force` option is only for
demonstrably pristine generated state; it is not a discard-submissions switch.

## Blindness warning

Cells omit references and hidden cases, but the shared `C:\dev` tree is not a
security boundary. Subjects can technically reach this experiment, `_tika`,
and historical solutions unless an external sandbox denies access. Without
such isolation, describe the study as procedurally blind and enforce the fixed
instructions. Never call the ordinary shared layout sandboxed.
